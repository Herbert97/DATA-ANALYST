# 1. Sistema Automatizado de Depósito Químico SILAR

## Descripción
Diseño y desarrollo de un sistema automatizado para deposición química de películas delgadas mediante el método SILAR, integrando automatización, programación embebida y diseño electrónico.

## Objetivos
- Automatizar el proceso de deposición química.
- Controlar parámetros operativos y movimiento del sistema.
- Implementar monitoreo y estabilidad operativa.

## Tecnologías utilizadas
- C++
- Altium Designer
- KiCad
- Electrónica de Potencia
- Sistemas Embebidos

## Actividades realizadas
- Desarrollo de programación embebida para automatización del sistema.
- Diseño de PCB multicapa para control y potencia.
- Implementación de control de movimiento y monitoreo de parámetros.
- Validación experimental del prototipo funcional.

## Resultados
- Construcción exitosa del sistema automatizado.
- Validación funcional mediante crecimiento de películas delgadas.
- Optimización de estabilidad y operación del sistema.

# 2. Análisis de Desempeño de Operadores en Call Center

## Descripción
Proyecto de análisis exploratorio de datos (EDA) enfocado en evaluar desempeño operativo de agentes de call center mediante métricas de productividad y eficiencia.

## Objetivos
- Identificar operadores con bajo desempeño.
- Analizar patrones operativos.
- Detectar posibles procesos automatizados.

## Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Jupyter Notebook

## Actividades realizadas
- Limpieza y transformación de datos.
- Eliminación de valores nulos y duplicados.
- Análisis de duración de llamadas y llamadas perdidas.
- Desarrollo de visualizaciones para análisis operativo.

## Resultados
- Identificación de operadores ineficientes.
- Detección de posibles bots automatizados.
- Generación de recomendaciones para optimización operativa.
