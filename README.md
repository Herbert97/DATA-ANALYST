# Proyectos


# 1. Análisis de Desempeño de Operadores en Call Center

## Descripción
Proyecto de análisis exploratorio de datos (EDA) enfocado en evaluar desempeño operativo de agentes de call center mediante métricas de productividad y eficiencia.

## Objetivos
- Identificar operadores con bajo desempeño.
- Analizar patrones operativos.
- Detectar posibles procesos automatizados.

## Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Jupyter Notebook

## Actividades realizadas
- Limpieza y transformación de datos.
- Eliminación de valores nulos y duplicados.
- Análisis de duración de llamadas y llamadas perdidas.
- Desarrollo de visualizaciones para análisis operativo.

## Resultados
- Identificación de operadores ineficientes.
- Detección de posibles bots automatizados.
- Generación de recomendaciones para optimización operativa.

# 3. Análisis de Pruebas A/B

## Descripción
Proyecto de análisis estadístico para evaluar el impacto de cambios en comportamiento y conversión de usuarios mediante pruebas A/B.

## Objetivos
- Validar hipótesis mediante análisis estadístico.
- Comparar desempeño entre grupos de control y prueba.
- Optimizar toma de decisiones basada en datos.

## Tecnologías utilizadas
- Python
- Pandas
- SciPy
- Matplotlib
- Jupyter Notebook

## Actividades realizadas
- Comparación de métricas entre grupos experimentales.
- Implementación de análisis estadístico.
- Visualización de resultados y tendencias.
- Evaluación de desempeño de variaciones.

## Resultados
- Identificación de variaciones con mejor rendimiento.
- Validación estadística de hipótesis.
- Recomendaciones orientadas a optimización de negocio.
